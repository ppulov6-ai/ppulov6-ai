# Ассистент ГРП

Архивное описание проекта PULAT FIELD CORE. Разработка прекращена по решению владельца.

Прототип приложения для Windows, предназначенный для подготовки документации ГРП: нарядов-допусков, схем расстановки техники и работы с полевыми файлами. Предусматривались редактирование схем, сохранение данных, работа с шаблонами Excel и локальная языковая модель.

Технологии: Python, настольный интерфейс, Excel, локальные GGUF-модели, сборка Windows EXE через GitHub Actions.

Описание фиксирует назначение разработки и не является подтверждением промышленной готовности или совместимости со всеми рабочими файлами.

26 октября 2026 года принято решение удалить исходный репозиторий, сохранив это описание. Фактическое удаление репозитория учитывается отдельно.
