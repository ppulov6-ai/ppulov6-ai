# Джарвис для Android

Архивное описание проекта. Разработка прекращена по решению владельца.

Экспериментальный голосовой помощник на русском языке для Android на основе открытого проекта KarakuriAgent/ClawDroid. Предусматривались текстовый чат, голосовые команды, плавающее окно и выполнение действий на телефоне через системные возможности Android.

Разрабатывались интеграция OpenAI Responses API, подтверждение важных действий, кнопка остановки, хранение ключей через Android Keystore и локальные команды поиска контактов, открытия звонилки и создания снимка экрана. Сборка APK выполнялась через GitHub Actions. Проверка сборки не означает подтверждённую работу всех функций на телефоне.

Технологии: Kotlin, Jetpack Compose, встроенный Go-компонент, Android AccessibilityService, OpenAI API. Исходная основа: https://github.com/KarakuriAgent/clawdroid , лицензия MIT.
